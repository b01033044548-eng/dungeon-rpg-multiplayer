# 던전 모험 RPG 멀티플레이

기존 HTML 게임에 Socket.IO 실시간 플레이어 위치 공유 기능을 연결한 프로젝트입니다.
현재 버전은 같은 링크에 접속한 플레이어가 같은 지역에 있을 때 서로의 캐릭터를 볼 수 있게 합니다. 게임 진행/아이템/몬스터 상태는 아직 서버에서 공유하지 않습니다.

## 내 컴퓨터에서 시험하기
1. Node.js 18 이상을 설치합니다: https://nodejs.org/
2. 이 폴더에서 터미널(명령 프롬프트)을 엽니다.
3. `npm install` 실행
4. `npm start` 실행
5. 브라우저에서 `http://localhost:3000` 열기

친구가 `localhost` 주소로 접속할 수는 없습니다. 친구에게 링크를 주려면 아래처럼 온라인 호스팅에 배포해야 합니다.

## 무료 Render 배포
1. GitHub에 로그인하고 새 저장소(repository)를 만듭니다.
2. 이 폴더의 `index.html`, `server.js`, `package.json` 세 파일을 저장소에 업로드합니다.
3. https://render.com 에 가입하고 GitHub 계정을 연결합니다.
4. Render에서 **New + → Web Service**를 선택하고 저장소를 연결합니다.
5. 설정값: **Build Command** = `npm install`, **Start Command** = `npm start`, **Instance Type** = `Free`.
6. **Create Web Service**를 누르고 배포가 끝날 때까지 기다립니다.
7. Render가 주는 `https://....onrender.com` 주소를 친구에게 공유합니다. 친구들도 그 주소로 접속합니다.

## 알아둘 점
- 무료 서버는 일정 시간 요청이 없으면 잠들 수 있고, 다시 접속할 때 깨어나는 데 시간이 걸릴 수 있습니다.
- 서버가 재시작되면 현재 접속자 목록은 초기화됩니다.
- 현재는 플레이어 위치/이름/직업/레벨/체력 표시만 공유합니다. 아이템, 골드, 퀘스트, 몬스터 체력, 저장 데이터는 아직 공동 공유되지 않습니다.
- 공개 링크를 아는 사람은 접속할 수 있습니다. 비밀번호 방 기능은 아직 없습니다.
